
Welcome to my AWS Cloud learning repository.

This repository documents my hands-on learning journey with Amazon Web Services (AWS). It contains notes, configurations, commands, troubleshooting experiences, and practical projects that I have completed while learning Cloud Computing.

AWS Services I am learning.

Overview of Topics – Introduction to the major AWS topics.<br>
Example: EC2, S3, RDS, Lambda, VPC, and other AWS services.

Cloud Computing – Provides computing resources over the internet.<br>
Example: Run an application on AWS without owning physical servers.

AWS – Amazon's cloud computing platform.<br>
Example: Use EC2 to run an application and S3 to store files.

AWS Account Setup – Creates and configures an AWS account.<br>
Example: Create an AWS account and configure billing and security settings.

AWS IAM – Manages users, roles, and permissions.<br>
Example: Give a developer permission to access only S3.

AWS CLI – Manages AWS resources using terminal commands.<br>
Example: Create an S3 bucket using the AWS CLI.

AWS EC2 – Provides virtual servers in the cloud.<br>
Example: Run a Node.js application on an EC2 instance.

AWS EBS – Provides persistent block storage for EC2 instances.<br>
Example: Attach an EBS volume to an EC2 server to store application data.

AWS AMI – Provides templates used to launch EC2 instances.<br>
Example: Create an AMI from a configured server and use it to launch new servers.

AWS ELB – Distributes incoming traffic across multiple servers.<br>
Example: Send users to different EC2 instances to balance application traffic.

AWS ASG – Automatically adds or removes EC2 instances based on demand.<br>
Example: Add EC2 servers when traffic increases and remove them when traffic decreases.

AWS S3 – Stores files and objects in the cloud.<br>
Example: Store images, videos, PDFs, and backups.

AWS RDS – Provides managed relational databases.<br>
Example: Run MySQL or PostgreSQL without managing the database server.

AWS DynamoDB – Provides a managed NoSQL database.<br>
Example: Store user profiles and application data with fast access.

AWS Lambda – Runs code without managing servers.<br>
Example: Resize an image automatically when it is uploaded to S3.

AWS CloudFormation – Creates AWS infrastructure using Infrastructure as Code (IaC).<br>
Example: Create EC2, S3, VPC, and other resources using a template.

AWS Route 53 – Provides DNS and domain management.<br>
Example: Connect myapp.com to an AWS application.

AWS CloudFront – Provides a Content Delivery Network (CDN).<br>
Example: Deliver website images and videos faster to users around the world.

AWS VPC – Creates a private network in AWS.<br>
Example: Place EC2 servers and databases inside a secure network.

VPC Creation – Configures networks, subnets, route tables, and gateways.<br>
Example: Create public and private subnets for an application.

AWS Billing and Organization – Manages AWS accounts, costs, and billing.<br>
Example: Monitor monthly AWS usage and organize multiple AWS accounts.

AWS Amplify – Helps build and deploy full-stack web and mobile applications.<br>
Example: Deploy a React application with an AWS backend.

AWS ECS – Runs and manages Docker containers on AWS.<br>
Example: Deploy a Dockerized Node.js application.

AWS EKS – Provides managed Kubernetes on AWS.<br>
Example: Deploy and manage containerized applications using Kubernetes.

Terraform – Creates and manages infrastructure using Infrastructure as Code.<br>
Example: Create EC2, VPC, and S3 resources using .tf files.

DNS Working – Explains how domain names are converted into IP addresses.<br>
Example: google.com is translated to the server's IP address by DNS.

SSL/TLS Certificates – Secures communication between users and servers through encryption.<br>
Example: HTTPS encrypts data exchanged between a browser and a website.
My goal is to build strong practical knowledge of AWS Cloud and develop the skills required to design, deploy, monitor, secure, and troubleshoot cloud infrastructure.

This repository will continue to grow as I complete more AWS labs and projects.
