
Welcome to my AWS Cloud learning repository.

This repository documents my hands-on learning journey with Amazon Web Services (AWS). It contains notes, configurations, commands, troubleshooting experiences, and practical projects that I have completed while learning Cloud Computing.

AWS Services I am learning.

IAM – Manages users, roles, and permissions.<br>
Example: Give a developer permission to access only S3.

EC2 – Provides virtual servers to run applications.<br>
Example: Run a Node.js, Java, or Python application on an EC2 server.

S3 – Stores files and objects.<br>
Example: Store images, videos, PDFs, and backups.

VPC – Creates a private network in AWS.<br>
Example: Put EC2 servers and RDS databases inside a private network.

RDS – Provides managed relational databases.<br>
Example: Run MySQL or PostgreSQL without managing the database server.

CloudWatch – Provides monitoring, logs, metrics, and alerts.<br>
Example: Get an alert when EC2 CPU usage goes above 80%.

Lambda – Runs code without managing servers.<br>
Example: Automatically resize an image when it is uploaded to S3.

Elastic Load Balancing (ELB) – Distributes incoming traffic across servers.<br>
Example: Send users between EC2 Server 1 and EC2 Server 2.

Auto Scaling – Automatically adds or removes EC2 servers based on demand.<br>
Example: Add more servers when application traffic increases.

Route 53 – Provides DNS and domain management.<br>
Example: Connect myapp.com to your AWS application.

AWS CLI – Manages AWS resources using terminal commands.<br>
Example: Create an S3 bucket from the command line.

Terraform – Creates and manages infrastructure using Infrastructure as Code (IaC).<br>
Example: Create EC2, VPC, and S3 resources using .tf files.

AWS Amplify – Helps build and deploy full-stack web and mobile applications.<br>
Example: Deploy a React application with an AWS backend.

ECS – Runs and manages Docker containers on AWS.<br>
Example: Deploy a Dockerized Node.js application.

EKS – Provides managed Kubernetes on AWS.<br>
Example: Run and manage containerized applications using Kubernetes.

My goal is to build strong practical knowledge of AWS Cloud and develop the skills required to design, deploy, monitor, secure, and troubleshoot cloud infrastructure.

This repository will continue to grow as I complete more AWS labs and projects.
